# 研发知识库

这里是 Agent 的研发方向知识库，按主题组织，适合用 `add_documents` 或 `scripts/ingest_knowledge.py` 入库后做语义问答。

建议目录：

- `architecture/` 架构设计、模块说明、技术选型
- `standards/` 开发规范、代码评审、安全规范
- `troubleshooting/` 常见问题、排障记录
- `api/` API 文档、接口约定
- `changelog/` 版本记录、迁移说明
- `handbook/` 新成员上手、环境搭建、操作手册

入库后可以问 Agent：

- “这个项目整体架构是怎样的？”
- “新增一个模块应该遵循哪些规范？”
- “遇到过 esbuild 平台不匹配的问题吗？”
- “API 调用超时一般怎么排查？”
