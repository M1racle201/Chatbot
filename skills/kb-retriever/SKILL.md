# 向量知识库检索

解决“用户自己的知识都放在向量库里，如何准确检索并基于原文回答”的问题。

## 何时使用

- 用户询问项目架构、开发规范、常见问题、API、版本记录、上手手册
- 用户要求“根据知识库 / 项目文档 / 资料回答”
- 需要确认某个说法是否在已入库文档中有依据

## 核心流程

1. 调用 `query_documents(query, top_k=3)` 检索（内部先命中子文档，再自动取回对应父文档）
2. 如果返回“向量库为空”，立即停止知识库回答，明确告诉用户先上传/入库数据，可用 `add_documents` 或 `scripts/ingest_knowledge.py`
3. 基于返回的父文档内容回答并标注来源；父文档不够或需要完整原文时，再用 `load(path, chunk=true)`
4. 检索结果不足时明确说明“知识库中没有相关内容”

## 工具选择

| 场景 | 工具 |
| --- | --- |
| 语义搜索 | `query_documents` |
| 读取完整原文 | `load(path, chunk=true)`（父文档不够时） |
| 把新资料入库 | `add_documents` |

## 边界处理

- 向量库为空时，只引导用户先上传/入库，不扫描文件系统或项目目录代答
- 只回答向量库检索结果里有依据的内容，查不到就明说不知道
- 检索结果里的来源缺失或文件不存在时，如实说明，不编造

## 禁止

- 不调用 `query_documents` 就直接凭印象回答
- 扫描文件系统或用项目目录结构代替向量库检索
- 向量库为空时仍扫描项目文件作答
- 编造来源，或引用不存在的文件
- 把大文件正文直接粘贴到终端
